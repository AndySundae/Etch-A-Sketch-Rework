# Etch-A-Sketch

This is a simple web page where you can select the canvas size and draw hovering your mouse over the pixels, just like an Etch-A-Sketch toy!

## Demo

try it here > https://andysundae.github.io/Etch-A-Sketch-Rework/

## Features

- Create a square canvas to a max of 100 pixels
- Draw by hovering your mouse over
- Change the canvas mode with the Crazy Mode button!
